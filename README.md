# RUNG — мультиагентная платформа перевода

## Описание
RUNG — это проект, в рамках которого разрабатывается система автоматического определения эмоциональной окраски текста (положительная, отрицательная или нейтральная).
Использует методы обработки естественного языка (NLP) — от классического машинного обучения (TF-IDF, Logistic Regression) до нейросетевых архитектур (LSTM, Transformers). Включает полный пайплайн предобработки текста и визуализацию результатов.

## Цель проекта
Автоматизировать процесс анализа пользовательских отзывов для бизнеса за счёт:
- быстрой обработки больших объемов текстовых данных;
- сравнения эффективности классических ML-моделей и нейросетей;
- выявления ключевых слов, влияющих на тональность (объяснимый ИИ).

## Стек технологий
- **Backend:** FastAPI, SQLAlchemy (async), Celery, Redis
- **LLM:** Ollama (qwen2.5), HuggingFace Transformers (NLLB, Qwen)
- **RAG:** BM25 (rank-bm25) + Qdrant + RRF-фьюжн
- **Эмбеддинги:** sentence-transformers (paraphrase-multilingual-MiniLM-L12-v2)
- **БД:** PostgreSQL 16, SQLite (для тестов)
- **Инфраструктура:** Docker, Docker Compose, Nginx
- **Оценка качества:** sacrebleu, bert-score, evaluate
- **Тестирование:** pytest, pytest-asyncio, pytest-cov
- **Python:** 3.12
